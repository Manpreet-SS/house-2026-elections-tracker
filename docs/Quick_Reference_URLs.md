## DATA COLLECTION WORKFLOW

### For Each Candidate, Follow This Order:

**Step 1 (15 min): OpenSecrets 2024 Cycle**
1. Go to OpenSecrets main race page (URL above)
2. Find candidate name
3. Click on candidate profile
4. Screenshot or record:
   - Total Raised (2024)
   - Cash on Hand
   - Top 5 PACs (with amounts)
   - Industry breakdown
   - Individual vs PAC split

**Step 2 (10 min): FEC Verification**
1. Go to FEC Candidate Search
2. Search by name and state/district
3. Find Committee ID
4. Go to "Receipts" tab
5. Download CSV for itemized contributions
6. Verify top PACs
7. Check for recent 2026 filings (if available)

**Step 3 (5 min): AIPAC Data**
1. Go to TrackPAC.org
2. Search candidate name
3. Record AIPAC contributions and endorsement status
4. Note: Data may be incomplete until closer to election

**Step 4 (5 min): Stock Trading (Incumbents Only)**
1. Go to House Clerk Financial Disclosures
2. Search member name
3. Download most recent Form 278
4. Record any trades from 2024-2026
5. Note dates and assets

**Total Time per Candidate: 35 minutes**
**For 11 Candidates: ~6 hours for complete research**

## TROUBLESHOOTING

### If OpenSecrets Page Shows Limited Data
→ Try refreshing the page or use browser back button
→ Check if there's a login wall (OpenSecrets is free, no login needed)
→ Try searching directly: opensecrets.org/candidates/search?name=[Candidate Name]

### If FEC Search Returns No Results
→ Make sure you're searching the right name spelling
→ Try searching by last name only
→ Look in the "Candidates" section, not "Committees"
→ 2026 new candidates may not be in FEC database yet

### If Track AIPAC Shows No Data
→ Candidate may not be in AIPAC's target races
→ Try alternate search: Citizens Against AIPAC Corruption website
→ AIPAC may not have posted 2026 endorsements yet

### If House Clerk Disclosure Shows No Recent Trades
→ Member may not be active trader
→ Trades must be reported within 30 days
→ Check prior years for baseline activity
